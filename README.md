# CodeAlpha Task 1 – Basic Network Sniffer

## 📌 Project Overview

This project was completed as part of the **CodeAlpha Cyber Security Internship – Task 1**.

The project is a **Basic Network Sniffer** developed using **Python and Scapy**. The purpose of this project is to capture and observe network traffic and understand the basic structure of network packets.

## 🎯 Objective

The objective of this project is to:

* Capture network traffic packets.
* Analyze basic packet information.
* Understand how data travels through a network.
* Learn about network protocols and packet communication.
* Gain practical knowledge of network packet sniffing.

## 🛠️ Technologies Used

* Python
* Scapy

## ▶️ How to Run the Project

### Step 1: Install Python

Make sure Python is installed on your system.

### Step 2: Install Scapy

Open Command Prompt or PowerShell and run:

```bash
pip install scapy
```

### Step 3: Run the Program

Run one of the Python files from the project folder:

```bash
python sniff.py
```

or

```bash
python sniffer.py
```
